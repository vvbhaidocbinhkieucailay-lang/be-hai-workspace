# Bản sao lưu

Mỗi gói `NMW_YYYYMMDD_HHMMSS[_nhan]/` gồm `db.sqlite`, `files/`, `manifest.json` (SHA-256, số bản ghi). Tạo/kiểm tra/diễn tập/khôi phục trong ứng dụng: Quản lí dữ liệu (SOP-04). Gói từ nơi khác: chép cả thư mục gói vào đây rồi bấm Kiểm tra.

Bản sao cùng máy không bảo vệ khỏi hỏng/mất máy – chép định kỳ sang ổ khác. Không tự xóa hoặc đẩy thư mục này lên Git. Trạng thái 06/10/2026: chưa có bản sao dữ liệu thật.
